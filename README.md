# 📊 Infográfico Interativo

Projeto desafiador concebido para transformar dados, tabelas e estatísticas densas em componentes visuais que sejam claros, atrativos e, acima de tudo, fáceis de assimilar.

## 💡 O Conceito por Trás

Em vez de obrigar o cliente final a acessar planilhas ou ler longos relatórios em texto corrido, este infográfico interativo busca proporcionar uma experiência de leitura gamificada e moderna, com um design atraente utilizando código estruturado nativamente para a web.

## 🛠️ Stacks Utilizadas

- **HTML5:** Utilizado para criar a marcação base e a organização semântica que sustenta a estrutura do layout.

## 📌 Guia Rápido de Uso

Para testar este repositório, basta executar os passos a seguir:

1. Faça o clone com o comando: `git clone https://github.com/jcrodriguesjr0/Infogr-fico-Interativo.git`
2. No seu gerenciador de arquivos, vá até o diretório do projeto.
3. Abra o arquivo raiz `index.html` com o navegador de sua preferência.
